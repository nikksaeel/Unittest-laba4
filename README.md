# Лабораторная работа №4: Unit-тестирование

В данной лабораторной работе реализованы функции вычисления геометрических параметров фигур и написаны Unit-тесты для них с использованием встроенной библиотеки Python `unittest`.

## Структура проекта

*   `perfg.py` — модуль с функциями вычисления **периметра** фигур.
*   `test_perfg.py` — Unit-тесты для проверки `perfg.py`.
*   `plosfg.py` — модуль с функциями вычисления **площади** фигур.
*   `test_plosfg.py` — Unit-тесты для проверки `plosfg.py`.

## Тестируемые функции

### 1. Вычисление периметра (`perfg.py`)
*   `triangle(a, b, c)` — периметр треугольника.
*   `rectungle(a, b)` — периметр прямоугольника.
*   `circle(r)` — длина окружности (периметр круга).

### 2. Вычисление площади (`plosfg.py`)
*   `triangle(a, h)` — площадь треугольника.
*   `rectangle(a, b)` — площадь прямоугольника.
*   `circle(r)` — площадь круга.

## Как запустить тесты

Для запуска тестов откройте терминал в корневой папке проекта и выполните следующие команды:

**Тесты для периметра:**
```bash
python3 -m unittest test_perfg.py
